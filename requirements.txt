PARTE 1: TODO LO QUE SE NECESITA PARA QUE EL PROYECTO FUNCIONE

--------------------------------------------------------------------------------



1. MATERIALES FÍSICOS (HARDWARE Y ESTRUCTURA)

   - Celular / Smartphone: Servirá como la pantalla que proyecta la interfaz.

   - Lámina de Acetato Transparente: Para armar la pirámide reflectora (efecto Pepper's Ghost).

   - Cartón o Madera: Para construir el soporte base que mantiene el celular a una distancia fija.

   - Tijeras / Bisturí, Regla y Pegamento / Silicona: Para ensamblar la pirámide y la base.



2. SOFTWARE Y ENTORNO DE DESARROLLO

   - Python 3.9+: Entorno backend para procesar la IA.

   - Editor de Código: Visual Studio Code u otro.

   - Navegador Web: Chrome, Edge o Safari en el celular o computadora.

   - Ollama (o API de OpenAI / Groq): Proveedor del modelo de IA (LLM).



3. LIBRERÍAS DE PYTHON (BACKEND)

   - fastapi: Framework ligero para crear la API REST.

   - uvicorn: Servidor web ASGI para ejecutar FastAPI.

   - requests / httpx / langchain: Para comunicarse con el modelo de IA.

   - python-dotenv: Para manejar claves de API o variables de entorno.





--------------------------------------------------------------------------------

PARTE 2: ¿CÓMO SE CONECTA UNA IA A UNA PÁGINA HTML? (ARQUITECTURA)

--------------------------------------------------------------------------------



La conexión NO se hace directamente desde HTML a la IA por razones de seguridad

y procesamiento. Se utiliza una arquitectura de 3 capas:



  [ FRONTEND ]             [ BACKEND ]                [ MODELO IA ]

  HTML + CSS + JS  <--->  Servidor Python  <-------->  Ollama / OpenAI / API

  (Proyecta en celular)    (FastAPI / Flask)           (Genera respuestas)



1. El usuario habla o escribe en la página web (HTML / JS).

2. JavaScript (Fetch API) envía el mensaje como JSON al servidor Python via POST.

3. El servidor Python recibe la petición, procesa el texto y consulta a la IA.

4. La IA responde al servidor Python con el texto generado.

5. Python devuelve esa respuesta en formato JSON a JavaScript.

6. JavaScript actualiza el HTML y activa animaciones o voz en la pantalla.

----- PASO A: BACKEND EN PYTHON (main.py) -----



from fastapi import FastAPI

from fastapi.middleware.cors import CORSMiddleware

from pydantic import BaseModel

import requests



app = FastAPI()



# Permitir conexiones desde cualquier origen (útil para probar en el celular)

app.add_middleware(

    CORSMiddleware,

    allow_origins=["*"],

    allow_credentials=True,

    allow_methods=["*"],

    allow_headers=["*"],

)



class PromptRequest(BaseModel):

    prompt: str



@app.post("/chat")

async def chat_with_ai(data: PromptRequest):

    # Ejemplo de llamada a servidor local Ollama (Llama 3 / Mistral)

    try:

        response = requests.post(

            "http://localhost:11434/api/generate",

            json={

                "model": "llama3",

                "prompt": f"Responde como una asistente holográfica llamada Cortana. Sé breve. Usuario: {data.prompt}",

                "stream": False

            }

        )

        ai_text = response.json().get("response", "No pude procesar la respuesta.")

        return {"response": ai_text}

    except Exception as e:

        return {"response": f"Error de conexión con la IA: {str(e)}"}



if __name__ == "__main__":

    import uvicorn

    uvicorn.run(app, host="0.0.0.0", port=8000)

----- PASO D: LÓGICA DE CONEXIÓN JAVASCRIPT (app.js) -----



async function sendMessage() {

    const inputField = document.getElementById("userInput");

    const responseBox = document.getElementById("ai-response");

    const userPrompt = inputField.value;



    if (!userPrompt) return;



    responseBox.innerText = "Pensando...";



    try {

        // Reemplaza 'localhost' por la IP local de tu PC si pruebas desde el celular

        const res = await fetch("http://localhost:8000/chat", {

            method: "POST",

            headers: {

                "Content-Type": "application/json"

            },

            body: JSON.stringify({ prompt: userPrompt })

        });



        const data = await res.json();

        responseBox.innerText = data.response;



        // Opcional: Síntesis de Voz en el navegador

        if ('speechSynthesis' in window) {

            const utterance = new SpeechSynthesisUtterance(data.response);

            utterance.lang = 'es-ES';

            window.speechSynthesis.speak(utterance);

        }



    } catch (error) {

        responseBox.innerText = "Error al conectar con el servidor.";

        console.error("Error:", error);

    }



    inputField.value = "";

}
